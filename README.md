# FairShare
A cost-splitting app, similar to Splitwise, that helps friends and groups share expenses fairly and see who owes whom.
**Live demo:** https://fairshare-tau.vercel.app/

## Features
- Add expenses and split them between people
- See who owes whom
- Simple, easy-to-use interface
- Works on desktop and mobile

## Tech Stack
- HTML, CSS, JavaScript (frontend)
- JavaScript (backend)
- Deployed on Vercel

## Getting Started
1. Clone the repository
   ```bash
   git clone https://github.com/mitalisonkiya/fairshare.git
   ```
2. Open the folder
   ```bash
   cd fairshare
   ```
3. Install dependencies
   ```bash
   npm install
   ```
4. Start the app
   ```bash
   npm start
   ```
